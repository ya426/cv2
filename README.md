# PRISM SR
Multi-Scale Hybrid Dense Attention Fusion Transformer for Single-Image Super-Resolution.

Upload **best.pt** from the companion Kaggle notebook beside app.py. The app loads
its architecture configuration and weights without training or downloading DIV2K.

The UI includes LR enhancement, bicubic/model comparison, reference experiments,
RGB PSNR/SSIM, matched detail crops, and PNG download. Reference mode generates a
bicubic LR input from the uploaded HR image. Arbitrary LR inputs have no reference metrics.

Inference uses context-padded tiles. The LR long edge defaults to 384 pixels for
CPU demos; larger inputs are resized and this is disclosed in the UI. Set the
MAX_LR_EDGE environment variable (32–768) to change this limit. CPU inference can
be slow. Tiled predictions can differ from full-image predictions; sharp detail
is an estimate, not proof of recovered original information.

This implementation uses fixed, alternating window partitions, multi-scale
convolutions, hybrid attention, dense fusion, and a bicubic residual. It is not
an exact reproduction of SwiseNet. Model quality depends on the uploaded weights.

Public Spaces expose the repository and uploaded checkpoint. Files generated by
inference are temporary; old exports are removed during subsequent requests.
